# Supplemental long-diverse admission diagnosis

Registered while fixed fits are running, before inspecting any A4 outcome.
This does not change the pre-fit implementation/source/data lock, research
budget, selection, scoring or frozen main diagnosis. It is read-only, metered
inference after final artifact locks, never an intervention or fitting run.

On first 32 development worlds, all four order siblings, diverse256 only,
seeds 1/7/19, matched E8/A3/A4, track the two annotated original stable signatures
at each four-byte completion. Record admission/non-admission, replacement of a
target, occupancy, target presence logits, number of positively recognized
existing units, incoming pair recognition, and its overlap with actual initial
records. Track losses during diverse filler separately from query-tail losses.
Reconstruct the unchanged admission choice externally from exported state and
frozen classifier weights; labels only categorize diagnostic records.

Attribute target removal to oldest-unrecognized replacement or full-protected
cache pressure from a positively recognized incoming pair. Report non-record
incoming false recognition separately, since arbitrary filler contains none of
the fixture record symbols. This tests whether slot pressure, classifier false
recognition, target recognition failure, initial non-admission or later state
changes cause the previously measured signature loss. Keep overlap-boundary
pairs separate from fully diverse filler windows. No predicted target label
enters model inference. Pin diagnostic source and checkpoints before execution,
verify source checkpoint hashes afterward, and retain input/padding/CPU costs.
