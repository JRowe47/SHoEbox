# A4 compact evidence

`prefit.json` locks passing receipts, complete fitting source hashes and generated
fold hashes before any fitting. `plan.json` fixes the nine independently charged
fits; `selection.json` locks all resulting model/cursor/world/result files.
`development.json`, `extended.json`, `update_metrics.json` and `benchmark.json`
retain original per-seed endpoints and timings. All prior directories remain
unchanged. A1/A2/A3/A4 audits are closed.

Frozen `conflicts_summary.json`, `matching_geometry.json`, `retention_summary.json`
and `geometry_summary.json` localize matching, occurrence/version ambiguity and
long-diverse loss separately. Their full per-occurrence vectors/events are in
the downloadable archive with all 18 fitted snapshots/cursors and generated
worlds. Locks, every process receipt/log and exact correctness-byte accounting
are retained. These are read-only diagnoses, not new research fits or audit use.

`accounting.json` in the parent directory sums process CPU once and itemizes
research/correctness/inference bytes, padding and local vector/objective updates.
Artifact-generation and packaging receipts are separate. No checkpoint, dataset
or compiled binary is stored in git.
