## Single next change

Keep A1's replacement rule and the existing state, local objectives, byte
calibration and 1/256 applicability prior. At query readout, evaluate the learned
key projection of each positively recognized record-phase candidate before
truncation. Rank by negative squared distance to the learned current query,
retain two candidates, then decode/mix their paired values with the existing
sigmoid attention rule. Exact distance ties use latest stored occurrence, then
stable slot/phase order. If fewer than two candidates are recognized, fill the
remainder from the historical presence ranking without duplicates. No parser,
byte equality test, source oracle, new slot, added coefficient or history tape.
Use a separate A2 checkpoint magic; never load A1/E8 as A2 implicitly.

This isolates query-dependent selection from the already measured admission
change. Do not introduce an unregistered matching tolerance, recency coefficient,
learned-state expansion or optimizer sweep. Overwrite ordering remains an
unchanged required endpoint. If query-first access helps competing bindings but
old/new versions still conflict, register occurrence-aware continuous matching
as the subsequent focused revision before fitting it.
