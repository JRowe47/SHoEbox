# Frozen occurrence diagnosis

No fit, coefficient selection or audit access. After the three-arm checkpoint
lock, inspect 32 development worlds/four order siblings for competing records
and overwrite, across all seeds and arms. At each answer, trace exact required
stable signatures, learned recognition, decoded keys/values, query distances,
shortlist membership, stored occurrence and native argmax. Overwrite separates
changed and untouched keys, old/new availability, both-version shortlist rate,
old-value predictions and exact distance ties. These are teacher-fed localization
measurements, separate from the registered autoregressive endpoint. Labels only
identify records in the diagnostic output; the inference API receives none.
Pin the diagnostic source and checkpoint hashes before executing it, preserve
all costs and never use the output to fit A2 again. Register any next revision
with fresh folds and unchanged gates before its own fitting.
