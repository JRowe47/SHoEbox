outcomes, including speed, were locked before diagnosis. Qualified E8 stays

## The exact intervention occurred

Each 2M continuation has 28,831 positive record-key events. A8 executes every
event; A9 executes 14,524 PAD-block events and omits 14,307 diverse-block events.
Across three seeds this omits 42,921 hybrid calls, 686,736 gradient rows,
10,987,776 code comparisons and 175,804,416 coordinate comparisons. No omitted
event runs a hidden gradient, and no retained event is repeated or rescaled.

All inputs, targets, labels and answer masks match A8. Exactly 38,567 spacer
bytes are replaced per A8/A9 continuation; 231,402 across both arms and seeds.
The complete world/stream manifest matches original blocked A9 byte for byte.
All 64 phases occur in both regimes; the incomplete final episode is retained.
Data-only coverage and fitted counters agree. The reduction in key credit is
the registered change, not a missing-data or cursor error.

independent affine output rows while preserving each row's floating-point
accumulation order. The current scalar candidate projection is visible in
`experiments/relative_chronological_retention/selection.hpp::a4_select`; its
inner row projections still use the scalar affine routine. This is a source
observation, not a new profiler measurement.

The speed shortfall is independently disqualifying. Resolve that execution
constraint before spending another fitting budget. A10 authorizes **zero
research fitting bytes**, no new scientific policy, no new accuracy scoring,
and no relaxed accuracy gate. It requires exact reference equivalence and the
same ≥80% native throughput threshold on a fixed fresh timing set. It is not
implemented or measured. A successful execution optimization would leave A9's
accuracy failure intact and require a later, separate accuracy preregistration.
